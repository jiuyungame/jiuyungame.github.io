# 九云游戏开发社 官方网站

站点内容由原 Wiki.js 知识库迁移而来，按板块存放在仓库根目录（`游戏开发技能/`、`妙脆角/` 等）。
单页板块直接写在根目录的同名 md 里（如 `友情链接.md`），多页板块用同名 md + 同名目录。

构建与部署使用社团开发的[NextCloud Pages](https://github.com/jiuyungame/nextcloud-pages)和
[Jekyll Authors Template](https://github.com/jiuyungame/jekyll-authors-template)；
模板本身的说明见 `docs/`。
