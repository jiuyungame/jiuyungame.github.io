# **社团吉祥物世界观以及角色设定汇总 by 黑糖混合颗粒**

**前言**：原本计划只设计角色形象和极简的性格身份设定，但是似乎这样的极简策略并不如预期一样达到便于二创的目的。所以这个文档会以角色设计者的角度，而非代表社团的角度，补充一些吉祥物的设计概念、捏他、世界观背景和经历，但是因为只是个人角度编写的，对于吉祥物们的解读和在创作仍然是自由的，这个文档有关的内容仅作为官方二创和设计的补充说明存在，不具有任何意义上的强制性和官方性质，请以轻松的态度来看待吧！

## **整体的设计概念和元素选取**

九云游戏开发社吉祥物的概念设计关键词包括：云、天空海洋与陆地、旅行、游戏幻想世界。三位补充角色和原本的社娘九一起构成了时间、海洋、天空、陆地四个维度，同时也对应着游戏开发中的策划、程序、美术、音乐四个工种。补充角色的初始服装也延续了九的初始服装的设计理念和元素，以电子旅行者为主题展开，服饰上大量借鉴了海陆空领域的制服装束，包括水手服、飞行员帽和外套、陆军贝雷帽、机长外套、空乘制服、学生制服等，核心点是制式服装的规整与专业感，和混搭穿着以及各种小配饰的个性化的碰撞与反差，体现社团的两大特点：学术科技类社团的专业和研究氛围和学生社团的兴趣化和个性化。

配色上选取了蓝色和棕色为主色调，蓝色一直是社团最有标志性的代表颜色，棕色在配合服饰设计的同时稍微中和了蓝色调的冷感。后续补充角色的服饰设计上，我主要注重了“一体感”，或者说团魂，因为初始服装是作为四人游戏工作室的制服或者代表服装而存在的，除了颜色以外，统一的点是水手服领（最能体现旅行者、专业人员和学生元素结合的服饰），较为厚重的服装（带有一点末世感觉，因为很“游戏”），眼镜样式的装饰物（护目镜，带有在极端环境工作、蒸汽朋克、研究员这些含义，其中九的配饰是滑雪护目镜，不过因为平时画都会简化所以看着没镜片，正经来应该看着是彩色的；程序归墟的配饰是潜水镜，因为她的象征是海洋，潜水镜搭配飞行员帽也颇有混搭感；美术文织云的配饰是墨镜，主要是找参考时搜了热气球驾驶员，他们一般都会佩戴墨镜，文织云的象征是天空，离太阳近，选用墨镜也比较合适；音效傅立叶的是篮球护目镜，一是封闭型带子设计比较方便挂胳膊上，二是她的象征是陆地，在陆地的运动怎么不算陆地呢，嗯。不过顺带一提的是这个护目镜大多数时候真的纯装饰，很少真正佩戴，尽管美术的墨镜最方便日常佩戴但是她自己就戴了一个近视眼镜）。

包括社娘在内，目前暂定的四个成员的中英文名字分别是：九（IX），归墟（NULL），文织云（Cirrostratus），傅立叶（Fourier）。中文和英文名之间不是严格的对照关系，存在某种内在联系和呼应关系，名字的具体释义我放到个人介绍中展开说了。

除此以外四个人物的起名历程也是十分波折，最初我一直纠结于让四人的名字连起来能组成一个词语，九云游戏或者九霄云外这样的，但是每次都总有至少一个人的名字因此很难定下来，所以最终还是放弃了，不过九云两个字倒还是保留了，所以能看到四个人的名字只有两个人含有九云，这是某个失败的藏头计划的遗留物，选中这两个人也没有什么特殊含义，只是正好她俩的名字决定的比较早。途中也尝试向AI寻求帮助，但是可能是我的要求和想法太多，他们给出的我都不满意，最后还是只让他们辅助找资料了。这里还有一些废案的名字。

九的废案名有：九云（好像有点太直白和方便了！虽然现在也挺直白的...）；九九（你敢相信吗有一段时间我有过干脆大家就叫九九云云悠悠西西的这种想法...），帧间（来源动画制作当中的关键帧和错帧，带有时间的意思，但是居然谐音真贱，这只能果断放弃了...）；九除（来源于数学当中的一种验算方法，弃九法。但是九除这个名字错就错在太拗口了），顺带一提其英文名也有一个废案Yesod，生命之树的第9源质，不过提到Yesod我的脑袋里总有一个紫色偏分头发的男人在...于是最后还是用了罗马数字的九，其他有关9的符号也考虑过，但是也都否决了。

归墟的废案名有：零值（这个作为英文名null保留下来了，选这个主要是因为她是程序，同时这个词在unity中给我带来过许多回忆...），残差（在找人工智能相关资料时看到的一个词，实际观测值与估计值之间的差，但是这个词中两个字都不是什么很正面的词，作为名字还是有些不妥。）；青霄（起完就后悔了，这么天空的名字居然不给到文织云，但是文的气质又不太适合这个有些隐居避世感觉的名字。不过看到这个废案应该就能看出是想组九霄云外，而其中的最大阻挡就是外这个字太难起名）。

文织云的废案名有：层云（和现在的大差不差，因为她的名字从一开始就决定要和云有关，现在的英文名Cirrostratus卷层云也是云的一种，如此钟情于层云是因为层云非常的美，非常的美术），其余的都是这个名字基础上的各种调整，所以说是最早决定的一个名字。

傅立叶的废案名有：弦外（这个人对九霄云外的外字起名能给出的唯一方案，但是还是觉得有点拗口和不像人名），囚牛（这是音乐人设的原型，龙之长子，喜好音律，不过这个名字有点过于本质，所以现在保留下来作为她最早的名字，而现在的名字是经过很长的岁月后起的化名中的一个），赫兹（这和傅立叶是一个选取原因，没用赫兹是觉得，既然都用赫兹了为什么不用分贝，这样的话程序可以叫字节，美术可以叫像素...还是别这样吧！），方波（从意思上确实很好，但是这个世界上有无数人真的叫这个名字，这倒无所谓。有所谓的是我身边就有一个方波...），频域（搜傅里叶变换时找到的，从含义上实在很适合，但是可惜拗口且不太像人名，音乐的名字实在让我纠结颇多，最后还是化用了傅里叶的名字）。

## **九IX的相关设定**

**九（IX）**也就是我们大家最熟知的社娘，名字来源于社团名，思来想去还是这个最顺口。IX除了代表罗马字母的九以外，还含有隐者牌的意思，和人物的经历有所关联。

以下是一些详细的角色设定：

**生日：**6月7日（取了被设计出来的那一天）

**身高：**160cm

**职业：**时空旅行者，策划（程序、引擎和绘画也会一些）

**爱好：**游戏开发，旅行（在各个游戏世界之间），沉思

**喜欢的东西：**各种奇特的交通工具，保质期很长的食品

**讨厌的东西：**漏雨的房子

**性格：**充满好奇心，喜欢结识新朋友，也喜欢独处

**人物经历：**没有来处和目的地的时空旅行者，似乎从有记忆时就在四处旅行了。随身带着许多自己设计制作的奇怪物件，其中包括一个用来操控其他机器的机器鱼，有时会被她称作鱼雷。对于九来说没有哪个世界是她“原本的”世界，于是在很长一段时间她都独自旅行，从不在某个地方过多停留，也不走回头路。不过在她接触到了一类名为“游戏”的“世界”后，她的想法也有了变化。因为她能穿梭于“游戏”和开发者的世界，因此对游戏开发（创造一个幻想世界）这件事产生了浓厚的兴趣，为了开发属于自己的游戏，九在旅行中开始学习游戏开发相关的知识，同时征集游戏开发伙伴。

在旅行中，饿肚子是常有的事，所以九每到一个有人烟地方就会尽可能的置办大量罐头食品。同时，她也有存放许多旅行日记和纪念品的场所，一个堪比异空间的折叠仓库。

## **归墟（NULL）的相关设定**

**归墟（NULL）**，名字来源于传说中的众水汇聚之处，角色的设定也融合了各种海神、海洋幻想生物。

以下是一些详细的角色设定：

**生日：**7月6日（还是取了被设计出来的那一天）

**身高：**148cm

**职业：**某个世界的规则制定和维护者（曾经），程序

**爱好：**游戏开发，钓鱼，实验奇奇怪怪的规则

**喜欢的东西：**在海里漂流打盹，鱼汤

**讨厌的东西：**虫子

**性格：**电波，经常沉浸在某件事里，寡言

**人物经历：**一个名叫My project (1)的游戏世界的管理者，从世界被原主人抛弃在旧电脑的角落后，归墟诞生了，并且根据留下的代码和素材继续着游戏的开发。My project (1)的原住民（NPC）们把归墟看作神，但是归墟却知道自己在这个世界只是个“空对象”。这个未完成的游戏最初似乎是个钓鱼游戏，有着海上钓鱼和上岸卖鱼这两个基础场景，归墟接管后按照渔村住民们以及自己的想法搞出了一堆自动钓鱼装置和各种奇形怪状的海洋生物，甚至增加了和鱼战斗，海底世界探索，和美人鱼谈恋爱等奇怪功能。不过对于归墟而言，她最喜欢的还是最基础的钓鱼功能。

有一天，一个自称九的旅行者来到了这个超级渔村世界，并且邀请归墟加入了她的游戏开发团队，尽管非常不舍，但是归墟还是暂时离开了My project (1)，跟着九去别的地方旅行。每隔一段时间归墟都会带回她新学会写的神奇功能和系统，让My project (1)变得更加包罗万象。

## **文织云（Cirrostratus）的相关设定**

**文织云（Cirrostratus）**，原型是黄胸织布鸟，文和织就来源于文鸟科织布鸟属。云以及英文名都来源于卷层云。

以下是一些详细的角色设定：

**生日：**3月23日（取了世界气象日）

**身高：**157cm

**职业：**天堂教育改造机关美术助教（曾经），游戏美术

**爱好：**游戏开发，ACG，画四格漫画

**喜欢的东西：**游戏，动画，三明治

**讨厌的东西：**画黑板报

**性格：**宅女，喜欢伪装阳角的阴角

**人物经历：**在某个世界的天堂作为天使工作，负责对不算好但没那么坏的灵魂们教育改造中的美术教育辅助工作，从画室毕业后就跟着老师当助教以及打杂。一直过着循规蹈矩的生活。直到有一天去人间出差时捡到了一本人类的漫画杂志，从而接触了漫画，动画，互联网...以及电子游戏。文织云还把这些ACG内容带到了其他天使中间，一时大家都扔掉教条书和课本去看漫画打电动，被天使长狠狠没收之后，大家商议要自己制作自己的漫画动画和游戏。之后不知经过多少会议、对峙、变革和教材的编写，最后天堂开设了针对改过灵魂的建模原画动画摄影游戏设计等新专业。

不过对于文织云来说，比起教别人建模原画动画摄影游戏设计，她更希望能和志同道合的人们一起开发游戏，于是在遇到旅行路过招募同伴的九之后，她也辞去了助教工作，跟着九一块组建游戏工作室去了。

## **傅立叶（Fourier）的相关设定**

**傅立叶（Fourier）**，最早的名字是囚牛，在漫长的人生中改过许多化名，现在的名字傅立叶（Fourier）来源于傅里叶变换。

以下是一些详细的角色设定：

**生日：**9月6日（取了囚牛的谐音）

**身高：**173cm

**职业：**自由网络音乐人，游戏音乐

**爱好：**游戏开发，所有种类的音乐，组乐队

**喜欢的东西：**合成器，音乐电台，蔬菜沙拉

**讨厌的东西：**解散

**性格：**老好人，喜欢尝试新事物

人物经历：傅立叶在她自己的世界活了很多很多年，在这些年里，她遇到过无数个在音乐上情投意合的人，但是结局都是分别，有时是因为各种意外和琐事离开，有时是病逝，或是寿终正寝。对于长生的神兽来说，相当于每个人和她聊了几天就消失了。傅立叶最初只是爱听音乐，但是随着岁月流逝，她也开始学习各种乐器，学习每个时代的各种音乐，以此结识各种各样的人。在她所处这个世界的当下，互联网和电子音乐盛行，傅立叶也创立了一个视频账号来发布音乐相关内容，加入各种群组寻找同伴。在这个期间，她经由网友的推荐接触了各种音乐游戏，成为她开始游戏开发的契机。

游玩这些音游似乎让她明确完善了她的目标，组建一支乐队，什么样的都行，摇滚，爵士，甚至交响乐。虽然一个人也能做音乐，但是傅立叶更喜欢大家一块其乐融融的样子。不过在九的游说下，她觉得似乎组建游戏工作室也挺好的！
